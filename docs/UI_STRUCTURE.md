# UI Page and Component Structure

## Pages
1. Home page: hero search, destinations, AI explanation, featured packages, alerts promo, testimonials, blog, FAQ, CTA.
2. Search results: summary, tabs, AI box, filters, package cards, provider lists, price breakdown.
3. Package comparison: side-by-side cards.
4. Package detail: complete package, risk notes, total cost, itinerary hooks.
5. AI planner: search plus prompt-driven planning modules.
6. Destination guide: SEO content blocks.
7. Blog: route and travel-cost guides.
8. Dashboard: saved trips, comparisons, exports, previous searches.
9. Price alerts: alert creation and premium upsell.
10. Login/register: auth placeholder.
11. Admin dashboard: providers, content, searches, conversions, prompts, commissions.
12. Affiliate management: provider setup table.
13. Pricing: free, premium, agency subscriptions.

## Components
- `Navbar`
- `SearchForm`
- `PackageCard`
- `PriceBreakdown`
- Future: `FiltersSidebar`, `AiRecommendationCard`, `FlightCard`, `HotelCard`, `TransferCard`, `EmptyState`, `LoadingSkeleton`, `ErrorState`.
